# CineNocturno

Sitio escolar de películas hecho con HTML, CSS y JavaScript.

## Archivos principales

- index.html: página principal.
- catalogo.html: búsqueda, filtro y favoritas.
- fantasia.html: sección de fantasía oscura.
- recomendaciones.html: películas recomendadas.
- contacto.html: formulario de recomendación.
- css/style.css: colores y diseño adaptable.
- js/script.js: filtro, favoritas, contador y validación.
- img/: imágenes locales del proyecto.

El sitio usa la rejilla de Bootstrap y las fuentes Cinzel y Poppins. El catálogo guarda las películas favoritas en localStorage del navegador. El formulario valida los datos y muestra una confirmación; no envía información a un servidor.

Las imágenes se guardan en img/. Se pueden reemplazar manteniendo los nombres de archivo o cambiando las rutas en las etiquetas img.
